## Week 2: Import Pipeline — Screenshot Upload + Claude Vision

**Goal:** User can upload a phone screenshot of their OnlyFans earnings page. Claude Vision extracts the dollar amounts and categorizes them.

### What Gets Built
- Import page (`/import`) — drag-and-drop zone + camera upload button + CSV upload zone
- Supabase Storage bucket for screenshots
- API route `POST /api/import/screenshot` — receives image, uploads to Supabase Storage, sends to Claude Vision
- Claude Vision prompt — extracts monetary values from OF dashboard screenshots, returns structured JSON (platform, category, amount, confidence)
- Transactions saved to Supabase `transactions` table with `ai_confidence` scores
- Loading UI with progress steps: "Uploading..." → "Reading your numbers..." → "Classifying..."

### Done Looks Like

- See AI processing animation
- Transactions appear in the database with correct amounts, categories, and platform tags
- Low-confidence items get flagged

You are analyzing a screenshot from a creator platform earnings dashboard.

## Week 7: Tax Engine — Estimation + Write-Offs

**Goal:** Quarterly tax estimate. Write-offs checklist. Deadline calendar.

### What Gets Built
- Tax estimation engine — calculates Federal income tax (progressive brackets) + Self-employment tax (15.3%) + State tax (varies by user's state)
- API route `GET /api/tax/estimate` — returns breakdown: gross income, deductions total, taxable income, federal tax, SE tax, state tax, total estimated, amount saved, shortfall/surplus
- Safe harbor calculation: compare to prior year (if available), suggest 100% or 110%
- Tax Write-offs page (`/writeoffs`) — structured checklist of OF-specific deductible expenses
- Each write-off item: category name, description (plain English), documentation needed, IRS form reference, checkbox (captured / not yet)
- AI auto-checks items based on detected transaction categories
- Progress bar: "You've captured 8 of 14 common write-offs (57%)"
- Deadline calendar on dashboard sidebar — next 2 quarters with dates and estimated amounts

### Done Looks Like
- /dashboard shows quarterly estimate with correct calculation
- /writeoffs shows checklist, AI pre-checks items it found
- Progress bar updates as user adds expenses
- Tax deadline calendar shows correct dates

### Tax Calculation Logic
```
Federal income tax = apply 2026 brackets to (taxable_income)
SE tax = taxable_income × 0.9235 × 0.153 (capped at $176,100 for 2026)
State tax = taxable_income × state_rate
Total quarterly = (federal + SE + state) / 4

Safe harbor = min(
  100% of prior_year_tax / 4,
  110% of prior_year_tax / 4 (if AGI > $150K)
)
```

## Week 8: Export + Payments

**Goal:** Users can export tax-ready data. Users can pay for Pro subscription.

### What Gets Built
- Tax Export page (`/export`) — Schedule C preview with: Gross receipts, Returns & allowances, Cost of goods, Total deductions (by category), Net profit
- API route `GET /api/export/schedule-c` — aggregates confirmed transactions into Schedule C format
- PDF export — generate a clean PDF report with all Schedule C line items, ready for CPA
- CSV export — downloadable spreadsheet with all transactions
- Stripe Checkout integration — API route `POST /api/stripe/checkout` creates a Checkout Session
- Stripe Webhook `POST /api/stripe/webhook` — handles: checkout.session.completed, customer.subscription.updated, customer.subscription.deleted
- Subscription management in Settings page — current plan, next billing date, cancel/upgrade
- Pricing page (`/pricing`) — Free vs Pro comparison, annual/monthly toggle ($19/mo or $190/yr)
- Legal disclaimer on all export pages: "Staxx provides tax-ready data, not tax advice. Review with a CPA before filing."
